## 📋 Descripción

Esta actividad tiene como objetivo evaluar **HTML, CSS y WCAG**, analizando su grado de cumplimiento en sitios web generados mediante Inteligencia Artificial.

Como objetivo secundario, se analizará el comportamiento de distintos **validadores de código y accesibilidad**, así como también de programas lectores de pantalla, considerando las pautas de accesibilidad y las posibles correcciones necesarias.

Para la actividad se generaron dos versiones de un mismo sitio web utilizando diferentes herramientas de Inteligencia Artificial:

- **ChatGPT**
- **Claude**

Ambas versiones fueron desarrolladas utilizando **HTML y CSS** y se encuentran publicadas mediante **GitHub Pages**.

## 🔎 Validación de los sitios

Para analizar el cumplimiento de los estándares de HTML, CSS y accesibilidad se utilizaron los siguientes validadores.

### HTML

**W3C Markup Validation Service**

https://validator.w3.org/

Utilizado para verificar la validez y correcta estructuración del código HTML.

### CSS

**W3C CSS Validation Service**

https://jigsaw.w3.org/css-validator/

Utilizado para comprobar la validez de las hojas de estilos CSS.

### Accesibilidad

**WAVE Web Accessibility Evaluation Tool**

https://wave.webaim.org/

Utilizado para analizar distintos aspectos relacionados con la accesibilidad web y las pautas WCAG.
